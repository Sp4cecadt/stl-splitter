# STL Splitter (PWA)

Client-side web app that splits 3D-print models into numbered, jointed parts that fit your printer bed.
No backend; everything runs and is stored on the device (IndexedDB). Works offline after first load.

## Stack
- three.js r187 (viewer, OrbitControls, TransformControls gizmo, STL/OBJ loaders), vendored in `vendor/three/`
- manifold-3d 3.5.5 (WASM) for repair, plane cuts, booleans, joint geometry, embossed numbers (`vendor/manifold/`)
- fflate (zip + 3MF read/write), own 3MF parser (handles Bambu/production-extension components)
- Plain ES modules + import map, no build step. IndexedDB for library, versions and photos.

## Files
- `index.html`, `styles.css`, `manifest.json`, `sw.js` (generated by `build_sw.py`), `icons/`
- `js/geom.js` repair / components / cuts / joints / numbering / split suggestions (DOM-free, Node-testable)
- `js/pack.js` orientation + MaxRects plate packing · `js/estimate.js` materials, filaments, printers, cost/time
- `js/export.js` STL / 3MF / zip writers · `js/loaders.js` STL / OBJ / 3MF import · `js/db.js` IndexedDB · `js/viewer.js` · `js/app.js` UI
- `test/` Node + Playwright tests and sample models

## Run locally
    python3 build_sw.py          # refresh the offline cache list after editing files
    python3 -m http.server 8777  # then open http://localhost:8777/

## Deploy
Copy the folder (or unzip `stl_splitter_pwa.zip`) to any static HTTPS host, e.g. GitHub Pages.
On iPhone: open the HTTPS URL in Safari → Share → Add to Home Screen.
